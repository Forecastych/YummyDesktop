# YummyDesktop

Неофициальный десктоп-клиент [YummyAnime](https://yummyani.me) для Windows.
Без рекламы, некоммерческий: тот же каталог, плееры, комментарии и аккаунт, что и на сайте,
плюс несколько удобств, которых нет в браузере.

> Проект не связан с администрацией YummyAnime. Все данные и видео берутся из публичного
> API сайта (`api.yani.tv`) и встроенных плееров. Приложение ничего не хранит на своих серверах:
> их нет.

## Что умеет

Всё основное с сайта: главная (онгоинги сезона, обновления, расписание на сегодня, анонсы,
новости), каталог с фильтрами, ТОП-100, случайное аниме, расписание, новости и статьи,
страница тайтла с выбором озвучки/плеера/серии, порядок просмотра, рекомендации, комментарии,
вход в аккаунт, списки, избранное и оценки.

Сверху:

- **Продолжить просмотр.** Локальная история: с какой серии, озвучки и секунды вы остановились.
- **Возобновление с места остановки**, **автопропуск опенинга/эндинга** (где он размечен)
  и **автопереход к следующей серии** с отсчётом. Работает в плеере Kodik: только у него есть API.
- **Подписки на новые серии** с уведомлениями Windows и счётчиком на колокольчике.
  Расписание можно отфильтровать «только мои подписки».
- **Запоминание озвучки и плеера** между тайтлами.
- **Отметка «просмотрено»** по серии, автоматически после 85% (если вы вошли).
- **Фильтр жанров с исключением:** клик включает жанр, второй клик исключает, третий сбрасывает.
- **Скорость:** кэш ответов в памяти и на диске (показываем сразу, обновляем в фоне),
  предзагрузка тайтла при наведении, ленивые постеры нужного размера, режим экономии трафика.
- **Горячие клавиши:** `Ctrl+K` или `/` для поиска, `Alt+←` или боковая кнопка мыши для «назад»,
  `F11` для полного экрана.

## Установка

Скачайте установщик `YummyDesktop_x.y.z_x64-setup.exe` со страницы
[Releases](../../releases) и запустите. Нужен WebView2: в Windows 10/11 он обычно уже стоит,
если нет, установщик поставит его сам.

## Сборка из исходников

Нужны [Node.js](https://nodejs.org) 20+, [Rust](https://rustup.rs) (stable, MSVC) и
[зависимости Tauri для Windows](https://tauri.app/start/prerequisites/).

```bash
npm install
npm run app      # режим разработки (vite на :1430 + окно приложения)
npm run release  # установщик в src-tauri/target/release/bundle/nsis/
```

Только фронтенд в браузере: `npm run dev`, затем откройте http://localhost:1430.
Проверка типов: `npm run check`.

### Токен приложения (необязательно)

API YummyAnime принимает заголовок `X-Application` с токеном приложения. Без него всё работает,
но лимиты запросов строже. Чтобы вшить токен в сборку, создайте `.env` по образцу
`.env.example`:

```
VITE_YUMMY_APP_TOKEN=ваш_токен
```

`.env` в репозиторий не попадает. Токен можно вписать и в настройках приложения.

## Устройство

- **Tauri 2** (Rust + системный WebView2): установщик в несколько мегабайт вместо сотни у Electron.
- **Svelte 5 + TypeScript + Vite.** Без UI-фреймворков, весь JS около 200 КБ (около 65 КБ в gzip).
- `src/lib/api`: клиент API (дедупликация запросов, LRU в памяти, stale-while-revalidate на диске).
- `src/lib/stores`: настройки, авторизация, история, подписки.
- `src/pages`: страницы, `src/lib/components`: шапка, карточки, плеер, комментарии.
- `src-tauri/src/lib.rs`: нативная часть (уведомления, полный экран, вход через окно сайта).

## Конфиденциальность

Логин и пароль уходят только на `api.yani.tv`. Токен сессии, история и настройки хранятся
локально на вашем компьютере. Никакой аналитики и телеметрии.
