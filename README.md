# YummyAnime Desktop

Неофициальный десктоп-клиент [YummyAnime](https://yummyani.me) для Windows.
Без рекламы, некоммерческий: тот же каталог, плееры, комментарии и аккаунт, что и на сайте,
плюс несколько удобств, которых нет в браузере.

> Проект не связан с администрацией YummyAnime. Все данные и видео берутся из публичного
> API сайта (`api.yani.tv`) и встроенных плееров. Приложение ничего не хранит на своих серверах:
> их нет.

## Что умеет

Всё основное с сайта: главная (онгоинги сезона, расписание на неделю, обновления,
рекомендации, новости, видео блогеров, анонсы, коллекции), каталог с фильтрами, ТОП-100, случайное аниме, расписание, новости и статьи,
видео блогеров с категориями,
страница тайтла с выбором озвучки/плеера/серии, порядок просмотра, рекомендации, комментарии,
вход в аккаунт, списки, избранное и оценки.

Сверху:

- **Продолжить просмотр.** Локальная история: с какой серии, озвучки и секунды вы остановились.
- **Возобновление с места остановки**, **автопропуск опенинга/эндинга** (где он размечен)
  и **автопереход к следующей серии** с отсчётом. Работает в плеере Kodik: только у него есть API.
- **Подписки на новые серии** с уведомлениями Windows и счётчиком на колокольчике.
  Расписание можно отфильтровать «только мои подписки».
- **Запоминание озвучки и плеера** между тайтлами.
- **Отметка «просмотрено»** по серии, автоматически после 85% (если вы вошли).
- **Фильтр жанров с исключением:** клик включает жанр, второй клик исключает, третий сбрасывает.
- **Скорость:** кэш ответов в памяти и на диске (показываем сразу, обновляем в фоне),
  предзагрузка тайтла при наведении, ленивые постеры нужного размера, режим экономии трафика.
- **Личные сообщения** с уведомлениями Windows о новых (отключаются в «Настройках»).
- **Смайлы в сообщениях:** наборы «смайлики папича» и YummyAnime из Telegram, кнопка у поля
  ввода. В тексте это код вида `:pp12:`, на сайте он так и виден, у нас — картинкой.
- **Мини-плеер поверх окон:** кнопка в плеере или `i` сжимает окно до маленького плеера
  в углу экрана, `Esc` возвращает как было.
- **Медиаклавиши и плитка Windows:** пауза, перемотка и следующая серия с клавиатуры
  и из системного оверлея громкости, с названием и постером.
- **Статус в Discord:** «Смотрит …» с серией, озвучкой и кнопкой на тайтл. Работает, если
  задан Application ID (см. «Discord» ниже); отключается в «Настройках».
- **Импорт списков из Shikimori** по нику или id: сначала показывает, что и в какой список
  ляжет, добавляет только после подтверждения. Тайтлы, которые уже в ваших списках, не трогает.
- **Правка и удаление своих сообщений** правым кликом, `↑` в пустом поле — править последнее.
- **Восстановление пароля** со страницы входа: письмо через окно сайта (там капча),
  новый пароль по ссылке из письма — в приложении.
- **Статус «в сети» на сайте,** пока окно приложения открыто. В трее — как закрытая вкладка:
  сайт покажет, когда вы были последний раз.
- **Горячие клавиши:** `Ctrl+K` или `/` для поиска, `Alt+←` или боковая кнопка мыши для «назад»,
  `F11` для полного экрана.

## Установка

Скачайте установщик `YummyAnime-Desktop-Setup-x.y.z.exe` со страницы
[Releases](../../releases) и запустите. Если приложение уже стоит, установщик просто обновит
его в той же папке; вход в аккаунт, история и настройки сохраняются. Нужен WebView2: в
Windows 10/11 он обычно уже стоит, если нет, установщик поставит его сам.

Установщик не подписан сертификатом, поэтому SmartScreen может показать «Windows защитила ваш
компьютер»: нажмите **Подробнее → Выполнить в любом случае**.

Дальше приложение обновляется само: раз в несколько часов проверяет Releases и предлагает
установить новую версию (кнопка есть и в «Настройках»). Установщик проверяется по подписи,
подменённый файл не поставится.

Версии до 0.3.0 назывались «YummyDesktop» и ставились в другую папку: после установки новой
удалите старую через «Приложения» Windows. История и настройки сохранятся.

## Сборка из исходников

Нужны [Node.js](https://nodejs.org) 20+, [Rust](https://rustup.rs) (stable, MSVC) и
[зависимости Tauri для Windows](https://tauri.app/start/prerequisites/).

```bash
npm install
npm run app      # режим разработки (vite на :1430 + окно приложения)
npm run release  # подписанный установщик и latest.json в release/
```

Только фронтенд в браузере: `npm run dev`, затем откройте http://localhost:1430.
Проверка типов: `npm run check`, юнит-тесты: `npm test` (vitest + jsdom, файлы `src/**/*.test.ts`).
Оба шага гоняет GitHub Actions на каждый пуш в `main` и PR (`.github/workflows/test.yml`).

### Выпуск версии

Обновления подписываются ключом minisign; публичная часть лежит в `src-tauri/tauri.conf.json`,
приватная — в `~/.tauri/yummianime-desktop.key` (или в переменной `TAURI_SIGNING_PRIVATE_KEY`).
Без приватного ключа выпустить обновление, которое примут уже установленные копии, нельзя:
храните его резервную копию.

1. Поднимите версию в `package.json`, `src-tauri/tauri.conf.json` и `src-tauri/Cargo.toml`.
2. `npm run release -- "что нового"`.
3. Создайте релиз `vX.Y.Z` на GitHub и загрузите в него все файлы версии из `release/`:
   `YummyAnime-Desktop-Setup-X.Y.Z.exe` — установщик для людей (окно в стиле приложения,
   проект `setup/`), `YummyAnime-Desktop.exe` — портативная версия, NSIS-установщик
   с `.sig` и `latest.json` — для автообновления.

Приложение берёт `latest.json` из последнего релиза, так что черновик и pre-release
обновлением не считаются.

### Токен приложения

По документации API YummyAnime ждёт заголовок `X-Application` с публичным токеном
приложения (создаётся на [странице приложений](https://ru.yummyani.me/dev/applications)).
Без него запросы пока проходят, но лимиты строже. Нужен только **публичный** токен:
секретный ключ клиенту не нужен и в сборку попадать не должен. Чтобы вшить токен в сборку, создайте `.env` по образцу
`.env.example`:

```
VITE_YUMMY_APP_TOKEN=ваш_токен
```

`.env` в репозиторий не попадает. Токен можно вписать и в настройках приложения.

### Discord

Для статуса нужен Application ID своего приложения Discord: создайте его на
[discord.com/developers/applications](https://discord.com/developers/applications)
(**New Application**, имя покажется в статусе, например «YummyAnime»). По желанию в
**Rich Presence → Art Assets** загрузите картинку с ключом `logo`: она будет вместо постера,
если постера нет. ID вшивается через `.env`:

```
VITE_DISCORD_CLIENT_ID=123456789012345678
```

или вписывается в «Настройках» приложения.

### Смайлы

Наборы лежат в `public/stickers/<префикс>/`, список — в `src/lib/stickers.json`. Скачать
или обновить набор из Telegram (нужен токен любого своего бота из @BotFather, в проект
он не попадает):

```bash
TG_BOT_TOKEN=... python scripts/fetch-stickers.py PolniyPakich pp emoji
TG_BOT_TOKEN=... python scripts/fetch-stickers.py yummyanime_stickers ym
```

Номер смайла привязан к картинке навсегда: если автор набора переставит или удалит
стикеры, старые сообщения покажут то же, что и раньше. `emoji` — показывать в строке
текста, `sticker` — отдельной крупной картинкой; без аргумента остаётся прежний вид.

## Устройство

- **Tauri 2** (Rust + системный WebView2): установщик в несколько мегабайт вместо сотни у Electron.
- **Svelte 5 + TypeScript + Vite.** Без UI-фреймворков, весь JS около 200 КБ (около 65 КБ в gzip).
- `src/lib/api`: клиент API (дедупликация запросов, LRU в памяти, stale-while-revalidate на диске).
- `src/lib/stores`: настройки, авторизация, история, подписки, списки, сообщения, статус Discord.
- `src/pages`: страницы, `src/lib/components`: шапка, карточки, плеер, комментарии.
- `src-tauri/src/lib.rs`: нативная часть (уведомления, полный экран, трей, вход через окно сайта).
- `src-tauri/src/mini.rs`: мини-плеер (геометрия окна и её возврат).
- `src-tauri/src/discord.rs`: статус Discord через локальный IPC-канал, без сторонних крейтов.
- `src-tauri/src/shiki.rs`: чтение списка Shikimori для импорта.
- `src-tauri/src/imgcache.rs`: дисковый кэш постеров.
- `src-tauri/scripts/player-agent.js`: агент внутри фрейма плеера (свои кнопки, MediaSession).

## Лог

Ошибки интерфейса, сбои запросов к API и падения нативной части пишутся в
`%LOCALAPPDATA%\io.github.yummidesktop\logs\yummianime.log` (до 1 МБ, затем файл
уходит в архив с датой в имени, хранится один прошлый). Папка открывается кнопкой в «Настройках →
О приложении». В лог идут только метод и путь запроса: query, тела, токены и тексты
сообщений туда не попадают.

Список изменений по версиям — в [CHANGELOG.md](CHANGELOG.md).

## Конфиденциальность

Логин и пароль уходят только на `api.yani.tv`. Токен сессии, история и настройки хранятся
локально на вашем компьютере. Никакой аналитики и телеметрии. Отметка «в сети» уходит
без идентификатора Яндекс.Метрики, который в неё кладёт сайт: поле `hash` пустое, как
у сайта с заблокированной Метрикой.

Сторонние сервисы — только по вашему действию: Shikimori запрашивается при импорте
(читается публичный список, ничего туда не пишется), а Discord получает статус через
локальный канал на вашем компьютере, пока статус не выключен в «Настройках».

HTML из новостей и описаний проходит через белый список тегов и атрибутов; встроенные
ролики — только с известных хостов и в `sandbox`. Политика CSP запрещает чужие скрипты,
а переход окна приложения на сторонний сайт перехватывается и открывается в системном браузере.
